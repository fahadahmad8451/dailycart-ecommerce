# DailyCart — E-Commerce Website

A responsive single-page e-commerce website built with **HTML5, CSS3, and vanilla JavaScript**. DailyCart was developed as my final internship project at DigiHub Software Company, where I practiced building a complete front-end shopping experience from scratch.

## Features

- **Dynamic product display** — products are rendered from a JavaScript array using DOM manipulation
- **Product search** — filter products instantly by name
- **Category filtering** — browse products by category
- **Shopping cart** — slide-in cart drawer with add, remove, and quantity update
- **Quantity & price calculation** — automatic totals with formatted prices
- **Cart persistence** — cart contents are saved in `localStorage`, so they survive page reloads
- **Checkout UI** — checkout form with JavaScript form validation
- **Responsive design** — layouts adapt to mobile, tablet, and desktop using Flexbox, Grid, and media queries
- **Toast notifications** — feedback messages for cart actions

## Technologies Used

- HTML5
- CSS3 (Flexbox, Grid, Media Queries)
- JavaScript (DOM, Arrays, Objects, Event Listeners, localStorage)
- Product images from Unsplash

## How to Run

No build step or server is required:

1. Clone this repository.
2. Open `index.html` in any modern web browser.

## Project Structure

```
├── index.html   # Page structure: header, hero, products, cart drawer, checkout, contact
├── style.css    # All styling, layouts, and responsive rules
└── script.js    # Product data, rendering, search/filter, cart logic, checkout validation
```
